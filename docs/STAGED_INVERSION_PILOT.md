# Fixed staged-inversion development pilot

Decision: test one computational hypothesis with four new prompt pairs and a fresh GS identity per reference. Stage27's delivery-path candidate remains closed. The original owner has finished its turn and main commit `6784879` proposes staged inversion as the next direction; no stage28 code or running worker was found at the ownership check. This implementation carries that proposal forward in a separate protocol.

The candidate uses 30 Adam updates with a 10-step proxy inverse, followed by four updates with the original 50-step inverse. Adam state carries across the switch. Each phase uses the reference image inverted with that same step count. No VAE delivery-path loss or target feedback is added. The native control calls the existing original Imprint core unchanged, with ten updates and 50 inversion steps. A fixed-short control uses fifty updates at ten inversion steps. Every arm budgets 500 forward UNet calls inside optimization, but actual core time including reference preparation is measured: equal call counts are not assumed to imply equal compute.

The working mechanism is that cheaper coarse trajectories permit more early updates, while final full-trajectory updates correct the coarse inverse's discretization bias. This is a hypothesis about computation allocation and the delivered endpoint, not a conclusion drawn from stage27's scores. The fixed-short control makes the necessity of full-trajectory refinement testable; within every chosen trajectory the implementation still uses full backpropagation.

The falsifiable expected gain is at least one additional ordinary-GS pass out of four and a mean message-accuracy gain of at least 0.02 over native Imprint. To attribute an effect to late refinement rather than cheap updates alone, the staged arm must also improve mean accuracy by at least 0.01 over fixed-short with no loss of pass count. Its median paired pixel-MSE ratio versus native must be at most 1.10. Both alternative arms' median core-time ratios must lie in [0.90, 1.10]. All four references must be valid. These are exploratory development gates, not significance tests or publication claims.

The fixed rule is in [28_staged_design.json](../protocols/28_staged_design.json). Complete evidence failing an efficacy gate closes this schedule. Missing evidence, invalid references or failed actual-cost matching is inconclusive. Any child engineering failure stops the run; outcomes remain preserved and there is no automatic retry, sample replacement, schedule search or threshold adjustment. All twelve candidate PNGs are sealed before twenty target inversions. The CPU finalizer independently decodes all saved inversions with evaluator-private state, checks pixel and timing metrics and applies the frozen decision.

## Prior-art boundary

- [Imprint, CVPR 2025 / author v3, §3.2 and §4.2](https://arxiv.org/html/2412.03283v3) already optimizes an unrelated model's inversion representation; the original experiment uses 150 optimization steps. Our low-budget pilot does not replace its full curve or establish superiority over the full method.
- [Shortcut Diffusion Optimization, §IV and §V, arXiv:2505.07477v1](https://arxiv.org/html/2505.07477v1) accelerates diffusion optimization through gradient shortcuts, with latent-optimization and adversarial-generation applications. Reducing backpropagation cost is established prior art. Our pilot changes the inverse discretization across updates and keeps full differentiation within each selected trajectory; this distinction is a mechanism description, not a novelty finding.
- [FARI, arXiv:2607.26723v1](https://arxiv.org/html/2607.26723v1) studies learned one-step inversion for watermark verification. We use existing frozen models and do not train or download an inverter. Prior work on fast inversion limits generic speed claims.
- [PGID, arXiv:2605.09319v2, §4.3, updated 13 October 2026](https://arxiv.org/html/2605.09319v2) uses progressive inversion-denoising cycles as a defense against Imprint. Its detection procedure differs from our attack-side allocation. Ordinary GS results here do not evaluate PGID or establish defense bypass.

The targeted search did not establish a new attack contribution. A positive pilot would justify independent tasks, matched-cost curves and direct acceleration controls; a negative pilot would reject this fixed allocation. No second candidate is launched: a more elaborate gradient shortcut presently lacks a demonstrated watermark-specific advantage over SDO and would enlarge the experiment before the simpler allocation is resolved.
