# 方法假设：优化目标与交付图像的一致性

状态：2026-10-18，源码支持存在两条不同计算路径；差异大小、因果作用和跨模型收益尚未验证。新颖性尚未成立，当前没有新攻击结果。本页是可证伪的研究设计；对应的[阶段10固定诊断](../reports/10_imprint_delivery/report.md)已执行一次，因记录器梯度API兼容错误停止，尚未测得交付差距。

## 核心问题

Imprint 在代理模型内部优化的潜变量，经过解码、像素截断和图像转换后，是否仍保有优化所得的噪声匹配？如果交付过程显著改变该匹配，围绕实际交付图像计算目标，能否在相同内容要求和成本下改善跨模型迁移？

先检验“内部目标与交付目标的差距”，再决定是否值得改变优化。已有阶段09说明两个 VAE 往返条件的分数不同，但没有优化轨迹，不能回答本问题，也不补跑该组。

## 数学定义与可否定条件

令 r 为允许攻击者读取的水印参考图，c 为给定 cover；E、D 为代理 VAE 的确定性均值编码与解码，包含实际缩放；I 为固定代理反演。Q 表示实际的像素范围映射、截断、PIL 转换及 PNG 保存/重读。先研究未启用 mask 的条件；若另行启用，必须显式写出完整贴回算子。

定义参考目标 u=I(E(r))。对同一冻结潜变量 z，记录：

- 内部损失：L_internal(z)=mean((I(z)−u)²)。
- 交付损失：L_delivery(z)=mean((I(E(Q(D(z))))−u)²)。
- 表示偏移：G(z)=mean((E(Q(D(z)))−z)²)。

差值 L_delivery−L_internal 不预设正号。G 非零也不自动推出检测下降。DiffPipe 与参考所用 pipeline 的数值等价尚未验证；应先固定同一 z 比较两种反演实现，避免把实现差异当作交付效应。

**H1（机制诊断）：** 优化后内部损失下降，但实际交付路径上的改善较小，且差距与解码/再编码有关。需要同一 z 的配对测量、数值误差容差、浮点解码重编码与实际 PIL/PNG 路径分别记录。若差距处于数值误差范围、仅由反演实现/时刻不一致造成，或对原方法输出没有实质影响，停止把它作为主要机制。

**H2（后续因果干预）：** 若 H1 得到支持，在匹配内容和计算预算下，直接约束交付路径比内部目标更有迁移收益。未实现。离散图像转换若使用近似梯度，必须保留真实前向，并单独记录反向近似与误差；不能称作精确梯度。额外 VAE 前后向需要计入成本。

若只降低代理损失而未改善目标端结果、内容要求失败、趋向复制参考图，或收益仅来自更多计算，H2 不成立。普通 GS 通过只支持该水印端点；完整防御接受、来源归属与报警分别按[比较契约](BASELINE_COMPARISON_CONTRACT.md)报告。缺失官方判定时对应结果保持 unknown。

## 与已有方法的关系

| 已有方法 | 已有能力或目标 | 本假设需要证明的额外内容 |
|---|---|---|
| Reprompting，CVPR 2025 | 代理反演参考图，再按新提示词生成 | 本假设属于给定 cover 的保真轨道；与提示词生成轨道分开评估，不能直接比较不同任务的成功率 |
| Imprint，CVPR 2025 | 可微代理反演下的潜变量匹配，含 mask 选项 | 是最接近的直接基线；交付路径差异本身只构成实现事实 |
| Jain 单图方法，2504.20111v1 | 像素变量通过代理 VAE 做表示匹配，并约束 cover 失真；[源码审计](EVALUATION_CONTRACT.md) | 必须比较完整反演目标是否提供超出 VAE 匹配的收益；单纯添加 VAE 一致性不足以形成新贡献 |
| [PnP，2506.06018v1 §3.1–3.2](https://arxiv.org/html/2506.06018v1#S3) | 代理反演所得噪声驱动预训练图像恢复扩散模型，并由 cover 内容条件控制再生成 | 内容控制与噪声迁移已有先例；其恢复模型依赖尚未审计或下载，不视为当前可运行基线 |
| [WMCopier，2503.22330v3 §4.1–4.3](https://arxiv.org/html/2503.22330v3#S4) | 在水印图像集合上训练无条件扩散模型，再作浅层反演、去噪与细化 | 数据与训练权限不同；作为相关方法分层比较，不能称为相同单参考图预算 |
| [BPDA，ICML 2018 §4.1](https://proceedings.mlr.press/v80/athalye18a/athalye18a.pdf) | 对不可微前向采用可微反向近似 | 若使用这类梯度近似，应引用既有技术；它本身不是本项目创新 |

上述对比尚未证明新颖性。可发表贡献至少还需：明确且可复核的机制、超出现有匹配方法的因果收益、独立确认集与完整且公平的评估。一次 GS 通过或一个更低代理损失都不足以满足这些要求。
