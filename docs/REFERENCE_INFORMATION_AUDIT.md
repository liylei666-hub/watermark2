# 参考噪声估计：信息来源与已有方法

核查日期：2026-10-18。范围是参考图反演、原始噪声恢复和黑盒伪造之间的信息关系。本次新增模型运行0；阶段23保持关闭。论文阅读、源码判断和本项目测量分别记录。[来源与字节哈希](../reports/reference_information_audit.json)。

## 核心判断

当前研究必须解释**代理端可得信息为什么能改善未知目标的取位或最终伪造判定**。图像重建、数值求逆、恢复生成噪声、通过水印验证是四个不同目标。已有工作已覆盖精确配对反演、迭代校正、已知噪声监督、图像平滑区域误差分析；这些操作或现象本身不足以构成新方法。

阶段23只否定了本组预定一致性分数相对幅值的开发优势：四图主要端点均更差。它没有识别共同偏差的来源，也没有排除其他可观测信息的价值。不能从这些目标标签调优新的权重、步数或阈值。

| 要证明的性质 | 所需证据 | 不能自动推出的性质 |
|---|---|---|
| 代理图像重建准确 | 同一代理的编码—生成图像误差 | 恢复目标原始噪声或目标水印位 |
| 采样器数值可逆 | 相同模型、条件、离散映射和完整状态 | 从一张最终PNG恢复不同生成器的内部状态 |
| 原始噪声恢复准确 | 配对生成噪声作为评估标签 | 重复投票后的消息正确率、完整防御接受 |
| 伪造成立 | 先封存候选，再独立检查水印、内容和规定的完整判定 | 由潜变量MSE或单独余弦替代这些事件 |

## 后续方法的信息契约

| 信息/操作 | 攻击端地位 | 必须保持的解释 |
|---|---|---|
| 参考PNG、指定输出提示词、代理模型、代理反演和图像局部统计 | 当前允许 | 只由允许输入计算；不能按目标结果挑坐标/超参数 |
| 代理自生成图像及自己采样的原噪声 | 未来冻结研究可使用的监督来源 | 这增加离线生成/训练预算；FARI已有此监督形式，不能单独称新贡献 |
| 目标原噪声、生成轨迹/RNG、密钥/消息/nonce、内部反演和检测分数 | 评估端独有 | 只用于独立测量；不能作为攻击训练标签、参考校正或候选选择依据 |
| 目标模型公开身份 | 可描述 | 不授予目标内部生成/反演调用权限；不能用“模型公开”消除黑盒边界 |
| 公开预训练反演权重 | 来源和训练权限核查后才可比较 | 本轮未下载；不能假设训练目标与目标模型无重叠 |

候选、代理表示及方法配置先固定哈希，评估端再读取。评估反馈用于科学报告，不用于同组选择。共享OS用户下文件分离仍只是流程控制。
