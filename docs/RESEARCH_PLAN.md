# 当前研究计划

更新：2026-10-16（Asia/Shanghai）。目标交付为方法、充分实验、可复现代码和论文初稿。当前阶段为研究审查，实验暂停。

## 核心问题

在参考关联明确、验证规则固定、攻击算法不读取目标内部信息或分数的条件下，代理端可计算的一致性约束是否能够提升具有指定内容的伪造图像的端到端接受率？若有提升，应能解释来自哪个处理环节。

该问题尚待验证；当前没有选定新方法。已有单图 VAE 匹配和语义过滤工作见 [文献矩阵](LITERATURE.md)。详见 [可行性审查](../reports/research_review.md)。

## 当前唯一优先任务

依据已完成的 [静态契约审计](EVALUATION_CONTRACT.md)，取得并冻结一个完整官方单样本评估材料包：优先闭合几何目标的参考获取/关联、局部数值规则、阈值与最终判定。公开材料继续缺失时，将具体缺项交由老师决定目标选择；保持文档与静态检查，不启动实验。

如果官方几何机制仍无法完整执行，保留其诊断身份，明确提出可执行评估对象的选择依据；不以自行补全实现冒充官方机制。

SemBind 最终会议版已包含端到端代理 masker 评估；公开代码仍主要提供语义哈希演示，不能假定完整 GS-S 可立即运行。Jain 核心 VAE 优化可以与目标反馈分离，但外层 GS ASR 汇总代码存在分数方向不一致，比较前须按原始判定语义核对。方法贡献须超出这些已有机制。

## 研究门槛

1. **协议成立：** 数据来源、模型版本、参考关联、阈值来源和信息权限可核查。缺失判定标 unknown。
2. **新颖性成立：** 明确区别于已有 VAE 匹配、语义编辑/候选过滤、布局控制；简单增加 loss 或重新命名不是贡献。
3. **试验有信息量：** 用户解除暂停后，优先做能识别混杂因素的最小对照。已有 [提示词对照设计](prompt_control_protocol.json)为待审查备选，尚未启动或冻结执行代码。
4. **成功定义完整：** 内容达成、伪造范围、原水印和完整验证通过同时报告。几何规则缺失时，仅报告分数诊断。
5. **确认集独立：** 方法固定后再冻结新提示词/种子/评估端水印材料；按密钥、提示词等采样层级统计，开发样本不充当未见确认集。
6. **论文可复核：** 公平预算基线、组件消融、失败案例、成本、模型/代码 revision、原始数据及 claim-to-evidence 对应齐备。

## 执行边界

实验暂停优先。已授权资源：物理 GPU 0、1、2、3、4、5、7 中确认空闲的一张；每次启动前核对 UUID、型号、显存、利用率和计算进程，使用单卡 cuda:0、串行、累计不超过 7200 GPU 进程秒、单进程 1200 秒、新增文件不超过 10 GiB、不下载新模型。失败/超时也计入预算，不抢占或终止他人任务。

仅使用获授权本地模型/数据。公开文献和官方代码读取、已授权 SSH 认证访问可用；不得网络扫描、第三方服务攻击、绕过访问控制或保存凭据。

攻击输入为参考图、指定输出提示词、代理配置、自身随机状态与预算。目标密钥/消息、原始噪声、随机状态、内部反演及分数属于评估端。候选先冻结并哈希再评估；算法无反馈与操作系统权限隔离分别陈述。
