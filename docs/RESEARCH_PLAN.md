# 当前研究计划

更新：2026-10-17（Asia/Shanghai）。目标交付为方法、充分实验、可复现代码和论文初稿。提示词与目标自身往返已完成，VAE 对照完成 2/3 后停止，当前持续核对机制解释与完整防御协议。

## 核心问题

在参考关联明确、验证规则固定、攻击算法不读取目标内部信息或分数的条件下，代理端可计算的一致性约束是否能够提升具有指定内容的伪造图像的端到端接受率？若有提升，应能解释来自哪个处理环节。

该问题尚待验证；当前没有选定新方法。已形成[交付路径一致性假设](METHOD_HYPOTHESIS.md)：先测量 Imprint 内部目标与实际交付目标的差距，再判断是否值得干预优化。已有单图 VAE 匹配和语义过滤工作见 [文献矩阵](LITERATURE.md)。详见 [可行性审查](../reports/research_review.md)。

## 当前推进顺序

下一项是冻结单参考图/单 cover 的代理路径一致性诊断协议与记录器，先排除反演实现和采样时刻混杂，再分解浮点 VAE 往返与实际交付转换。该机制诊断可以独立于完整防御材料推进；完整防御比较仍需参考与固定工作点。SEAL 的 [源码审查](SEAL_EVALUATION_CONTRACT.md)已显示语义路径与穷举路径不可混用，另需 caption/embedding 权重；本轮不下载。几何与 SemBind 缺项不由自编替代算法填补。

理论适用条件的 [闭式审查](../reports/geometry_proof_obligations.md)已把全局角度、局部谱偏差和维度集中分别列为证明义务。理论 AND 拒绝区域已知，实际固定工作点仍缺。下一项静态工作应将这些条件与官方参考关联和可执行样例逐项对应；不要把一般数学例子当成模型可实现攻击。

当前待验证的问题是：几何分数能否区分明确的伪造与图像处理误差，而不是仅区分两个模型流程。已有小样本不能回答总体可靠性；先闭合成功定义和既有方法边界，再决定新的独立实验组。预算剩余不构成无目的增加样本的理由。几何论文已经包含重建基线与后处理分析，Jain 已有 VAE 匹配；当前对照不单列创新，需通过完整规则与独立验证建立实质区别。

[CSI 公开库审查](CSI_INFORMATION_CONTRACT.md)已把一项权限未知转为确定：该实现使用检测失败反馈，不能直接作为零目标反馈方法；其 SEAL 是另一个数值重实现。[攻击比较契约](BASELINE_COMPARISON_CONTRACT.md)已定义 query 权限、候选数/生成数、任务轨道、内容要求和统计分母；[内容评审规则v1](CONTENT_ADJUDICATION.md)已定义；具体任务判据、人员与配置仍需在实验前冻结。保留主体与语义过滤已有公开机制，不作为本项目独立创新。

错误来源归属与未报警伪造是两个端点，见[比较契约](BASELINE_COMPARISON_CONTRACT.md)。后续方法假设必须保持受害者密钥固定、只修改攻击者交付图片；近邻密钥连续性检查只用于理论边界审计。当前继续方法差异与可证伪假设设计，完整防御实现缺项仍是模型实验的准入条件。

## 研究门槛

1. **协议成立：** 数据来源、模型版本、参考关联、阈值来源和信息权限可核查。缺失判定标 unknown。
2. **新颖性成立：** 明确区别于已有 VAE 匹配、语义编辑/候选过滤、布局控制；简单增加 loss 或重新命名不是贡献。
3. **试验有信息量：** 先做能识别混杂因素的最小对照；提示词控制代码与协议已冻结，工程失败停止整组且不重试。
4. **成功定义完整：** 内容达成、伪造范围、原水印和完整验证通过同时报告。几何规则缺失时，仅报告分数诊断。
5. **确认集独立：** 方法固定后再冻结新提示词/种子/评估端水印材料；按密钥、提示词等采样层级统计，开发样本不充当未见确认集。
6. **论文可复核：** 公平预算基线、组件消融、失败案例、成本、模型/代码 revision、原始数据及 claim-to-evidence 对应齐备。

## 执行边界

本轮已恢复实验，授权资源为物理 GPU 0、1、2 中确认空闲的一张；每次启动前核对 UUID、型号、显存、利用率和计算进程，使用单卡 cuda:0、串行、累计不超过 7200 GPU 进程秒、单进程 1200 秒、新增文件不超过 10 GiB、不下载新模型。失败/超时也计入预算，不抢占或终止他人任务。十一进程累计已用 757.622 秒，剩余 6442.378 秒；不得重置累计预算或重试已停止的阶段 09。

仅使用获授权本地模型/数据。公开文献和官方代码读取、已授权 SSH 认证访问可用；不得网络扫描、第三方服务攻击、绕过访问控制或保存凭据。

攻击输入为参考图、指定输出提示词、代理配置、自身随机状态与预算。目标密钥/消息、原始噪声、随机状态、内部反演及分数属于评估端。候选先冻结并哈希再评估；算法无反馈与操作系统权限隔离分别陈述。
