# 代理监督的跨生成器检验契约

日期：2026-10-18。研究问题：代理自生成数据提供的原噪声监督，能否改善另一生成器参考图的水印位恢复？本轮完成先例核查、数值设计和CPU估计器；实际模型数据尚未生成。[机器证据](../reports/cross_generator_contract.json)，[固定设计](../protocols/24_cross_generator_design.json)。

## 已有方法覆盖

FARI v1 §3.2、§4.3、E.2分别覆盖原噪声监督、生成条件泛化和其他模型结果；固定公开代码的train.py、val_gs.py在同一模型pipe上生成和反演。这些材料未展示我们需要的“只用SD2.1监督训练，固定后测试SDXL生成图像”的GS伪造链路。不能由此声称全部相关工作都没有该比较。其移除攻击依赖原始噪声，与当前攻击信息权限不同。[FARI原文](https://arxiv.org/html/2607.26723v1)，[完整源码审查](REFERENCE_INFORMATION_AUDIT.md)。

There and Back Again当前版本是**2410.23530v5，2026-01-27**，并有[ICLR2026正式出版记录](https://proceedings.iclr.cc/paper_files/paper/2026/hash/233278d812e74a4f9848410881db86b1-Abstract-Conference.html)。[v5 §4 Eq.(5)、附录F Algorithm1](https://arxiv.org/html/2410.23530v5)用新采样Gaussian噪声执行早期前向扩散，再继续反演，主要测量去相关、重建和编辑。它不需要目标生成轨迹作为该修正的输入。基础误差定位中的真值干预与这个可执行方法须分开。

本项目推论：独立随机噪声可以改变估计误差，但没有直接携带原始水印位标签；去相关或编辑改善不能单独证明原始位恢复更准确。这个判断不排除实际有益效果，也不是关于所有反演器的不可能性结论。

## 固定的机制检验

先使用一个小型线性诊断估计器，判断最简单的代理监督能否产生跨域收益。它不训练扩散模型，不作为FARI复现或新攻击。选用低容量、闭式拟合，是为了让数据来源和迁移问题可检查；若失败，只关闭这个固定估计器，不能否定所有学习式反演。

每个空间位置取代理50步反演的4通道值及4通道3×3局部均值，共8个特征。边界reflect填充，特征均值/标准差只在训练集上估计，标准差下限1e-6。加入截距，用4通道代理原始噪声作标签。目标为逐空间位置平均平方误差加0.001倍系数平方和，截距不惩罚；float64闭式求解，共36个拟合系数。只拟合一次，不做超参数或特征搜索。

| 数据角色 | 数量及来源 | 可读取标签的过程 |
|---|---|---|
| 训练 | 16张SD2.1自生成Gaussian图，4提示词×4种子 | CPU拟合器；仅代理自己采样的噪声 |
| 验证 | 8张SD2.1 Gaussian图，2个独立提示词×4种子 | 固定通过条件检查；不调整模型 |
| 同域测试 | 8张SD2.1 GS参考，4个新提示词×2种子 | 封存预测后的评估端 |
| 跨域测试 | 8张SDXL GS参考，与同域测试共用提示词，但噪声种子和加密状态独立 | 封存预测后的评估端 |

全部提示词、种子、模型revision、参数和停止条件见设计JSON；历史样本不进入拟合或新测试。相同提示词用于描述生成器变化，不能共享原始噪声给攻击端。GS测试每图独立消息/key/nonce，秘密状态仅保留评估端。

保持现有缓存快照、512、FP32、官方DDIM生成50步/CFG7.5，代理反演50步/空提示词/CFG1。跨域变化同时包含生成器和VAE差异，不能单独归因为其中一个组件。

验证通过条件是8张图平均MSE严格改善，且平均原噪声位错误率不变差。若未通过，停止本设计，不启动两个测试集、不改参数补救。通过后先封存估计器、源数据和配置，再生成测试参考；所有代理预测封存后才读取测试标签。

主要端点为8张目标参考上“原始代理位错误率减校正后位错误率”的逐图差和均值，并按4个提示词分组展示。同步报告同域GS测试和原噪声MSE。消息解码准确率若计算，仅表示估计位的诊断结果；本设计没有目标反演、候选攻击图或完整防御检测，故目标检测成功率及攻击成功率保持unknown。

这是小样本开发诊断。空间坐标不是独立样本；不作总体显著性、概率校准或顶会级收益声明。即使通过，仍需独立样本及固定候选的端到端检验。
