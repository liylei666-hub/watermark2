# Research scope

This repository studies instance authenticity under an explicit allowed-edit policy.
The research question is provisional. CCF-A is a target, not an acceptance or novelty claim.

- Read `research/problem.md`, `research/literature.md`, and `research/validation.md` before extending experiments.
- `legacy/` preserves prior code and evidence. Do not relabel its results as new experiments.
- Keep calibration, development, and test families disjoint. Report achieved benign acceptance, all attack attempts, and full-verifier acceptance.
- Use only owned or authorized images. Do not launch training, large downloads, paid APIs, or GPU jobs without an explicit execution budget.
- Run the CPU checks in the README. Keep failures and unavailable evidence visible.
- Preserve history and recovery refs; never force-push or overwrite concurrent remote work.
