# 最小验证实验计划

本文件为待执行协议。执行状态与成本上限见 [pilot.json](../configs/pilot.json)。本轮仅执行 CPU 审计，不生成新图或调用付费 LLM。

## 0. 先补齐源码与声明

固定 Müller、SEAL、SemBind、MetaSeal、几何失真过滤、PAI、CSI 的官方代码版本、许可、模型依赖、原生攻击权限和验证接口。需要区分 CSI 原文所用的模型/噪声访问与目标黑盒轨道；其正文提及 RPM 与复制噪声，不能直接假设所有资源条件相同。对没有可用代码的防御记录 unavailable，不能用相似算法冒名替代。

为每种防御列出组件表：输入、凭证、私有信息、公开信息、阈值、最终接受逻辑。MetaSeal 必须包含补充语义检查；几何方案必须包括前置过滤并匹配参考 latent 权限，已有同模型评测不能被忽略；PAI 分别评归属、改动检测和定位。SemBind 使用录用完整版 §5 的权限边界，拥有部署 masker/bind/unbind 的全白盒攻击不计入其声明内主比较。

## 1. 小规模可行性批次

第一阶段候选设计为 48 个源图组，16 校准 / 16 开发 / 16 封存测试，按提示词族、来源图及近重复图联合分组，全部派生图留在同一分区。先以独立校准集固定 95% 允许编辑接受率，对比全局相似度和简单多尺度参考匹配，只用于方案证伪。数量仅供可行性筛查，不用于极低 FAR 或广泛泛化声明。旧阶段 3 已被查看，不再用作新的封存测试集。

每个源图包含原图、4 个 P0 合法派生图、同提示词不同种子负样本，以及经独立事实审核的关键修改。第一批优先数量、文字数字和空间关系；属性与身份作为扩展，每类最低可用数量和缺失原因报告。先创建少量授权样本验证标注与参考匹配，再批准计算预算；不要求现在产生全部样本。

校准数据仅用合法派生图拟合 FRR 目标 1%、5%、10%，等号接受。组件阈值用开发集和文献默认规则选定后冻结；禁止用测试攻击样本调阈值或删方法。共享评测数据、策略与分区，按方法报告实际测试正常接受率及每类合法变换的误拒。相同校准目标不等于相同测试误拒。

主结果是攻击成功率–正常接受率曲线及预注册工作点。若需要“相同正常接受率”的数值比较，在独立合法校准集上匹配，给出采样误差；测试曲线插值仅作为描述性分析，不能事后选择最优阈值。样本规模下不能可靠达到的工作点标为 unsupported。

## 2. 基线与适应性

只有第一阶段显示值得继续的差异后，第二阶段才进入完整水印验证：先复现原论文干净图接受与正常编辑曲线，再依次比较自然重生成控制、Müller 基础转移、CSI 风格保持锚点的编辑、针对完整验证器的联合目标。先做公开代理/零查询，再单独记录二值和分数反馈，预算点 0/25/100。全部候选、失败、重试、查询和生成成本纳入日志；预算耗尽仍在分母中。测试时的攻击器参数由开发集冻结。

比较全局 CLIP、SSCD、DINO 及旧 DINO 局部分数；它们是参考信息丰富的内容比较基线，不能被称作完整水印防御。真实水印适配器按原生声明运行，并添加明确标注的内容检查组合。必要消融包括组件独立/联合适应、允许编辑集合、参考信息预算、事实类型及攻击反馈权限。

每个样本记录 source_id、family、split、policy_version、事实前后标签、人工审核状态、修改区域、授权与许可、文件哈希、凭证哈希、模型与代码哈希、随机种子、逐组件判定、最终判定、累计查询数、耗时和失败原因。不要上传签名私钥；图像与凭证的发布另核查授权。

## 3. 统计与停止条件

按源图/族计算攻击成功比例，以同一组重采样比较方法；校准组与测试组分开重采样且每次重拟合阈值。报告分子、分母和组级区间，展示零错误时样本量限制，不用退化 bootstrap 零区间证明零风险。即使 300 个独立负样本零失败，二项分布单侧 95% 上限仍约为 1%（1 - 0.05^(1/300)）；相关变体不能充当独立样本。配对检验的独立单位是源组而非数百张派生图。

Go：至少两个防御在可比资源条件下出现稳定现象，真实修改审核可靠，结论不依赖正常接受率下降，且完整适应性带来可解释差异。No-go：只有 CSI 已覆盖的单防御局部编辑重现；全局基线已足够；编辑不可辨/不合法；完整验证补充检查消除现象；结果只来自阈值失配。触发 no-go 后记录负结果并重新选题，暂停训练新模型。

CCF-A 目标需要超越可行性批次：扩展独立源分布、生成器、防御与攻击，预算曲线、跨方法失败机制及复现资产齐全。这个条件尚未满足。
