# 几何可分性：定理适用条件核查

核查日期：2026-10-16。对象是几何论文 ICML 2026 最终会议版 §4.3、附录 B.3 的 Lemmas 4.6/4.9 与 Theorem 4.10。结论：理论拒绝区域可明确，但将其用于本项目，需要补充维度增长、局部谱偏差和集中界条件。以下是推理适用范围审查，尚未证明受限攻击可绕过实际防御。

## 1 正交误差的大小需要相对于潜变量能量定义

Lemma 4.6 的证明分解 `δ=αz+δ⊥`，在小扰动条件下近似 `cos θ ≈ 1−||δ⊥||²/(2||z||²)`，再由高斯范数 `||z||²≈N` 和正交能量严格为正推到 `E[θ]=Ω(1)`。这里需要进一步说明正交能量随 N 的增长；正值本身不足够。

本项目的闭式例子：令 `Z_N~N(0,I_N)`，N≥2；取与 Z_N 正交的可测单位向量 u(Z_N)，令 `δ_N=aZ_N+u(Z_N)`，a 为任意小的固定正数。u 可用 e₁ 在 Z_N 正交补上的归一化投影构造，概率零的退化位置另选正交单位向量。则

```
||δ_perp||² = 1
E[||δ_N||²]/N = a² + 1/N → a² > 0
θ_N = atan(1 / ((1+a)||Z_N||)) → 0  （依概率）
E[θ_N] → 0                         （有界性推出）
```

因此，非零的每维 MSE 下界与严格正的正交能量可以同时成立，而期望角度仍趋零。此处使用精确角度公式，不依赖 Taylor 截断；a 固定时相对扰动趋近 a，而非趋零。若要求严格的相对扰动 o(1)，去掉 aZ_N 项仍说明“正交能量为正”单独不够，但不再具有非零的每维 MSE 下界。

这不是可执行攻击：构造直接引用 Z_N，未满足攻击者仅持参考图和代理模型的限制，也未证明能由代理生成/反演实现。实际需要核对的是：论文代理失配条件是否能推出关于 `||δ⊥||/||(1+α)Z_N||` 的维度一致下界及非消失概率；仅知道总 MSE 不够。

## 2 AIRM 的不变性与相对谱偏差

Lemma 4.9 正确写出了同时合同变换不变性：`d(P,Q)=d(GPGᵀ,GQGᵀ)`。这不等于 `d(P,GPGᵀ)=0`。例如 P=I_d、Q=4I_d，则 `Q=(2I)P(2I)ᵀ`，但 `d(P,Q)=sqrt(d)·log(4)>0`。

事实上任意两个 SPD 矩阵都可通过某个可逆 G 作合同关联。因此“存在某个 G”本身不能区分正常和伪造。论文伪造分支明确限定 G **充分接近单位矩阵**，正常分支也额外假设估计误差可忽略；审查必须保留这两项条件。需要量化的是邻域、相对谱偏差及其概率，而不是否定合同不变性。

附录随后假设 `S=P^(-1/2)QP^(-1/2)` 以至少 p₀ 的概率存在对数特征值绝对值≥η₀，其中 η₀、p₀ 不消失；在该条件下 `E[d(P,Q)]≥η₀p₀` 的步骤成立。未闭合的是实际受限代理扰动如何保证这个条件，以及正常重建如何保证相反方向。

数值条件也影响从协方差误差到距离的推理：Pε=diag(ε,1)、Qε=diag(2ε,1)，其 Frobenius 差为 ε→0，但 AIRM 恒为 log 2。这说明接近奇异边界时绝对误差不足以给出统一控制；它并不反驳固定正则下远离奇异边界的连续性。官方 ε、精度及截断尚未在公开实现中闭合。

## 3 高斯集中界需要追踪 Lipschitz 常数的尺度

Theorem 4.10 的证明明确承认“期望分离”不足，随后借助 Lipschitz 条件与高斯/球面集中；不能描述为作者忽略了集中论证。需补足的是由这些条件到 `exp(−Ω(N))` 的维度依赖。

标准欧氏高斯的 L-Lipschitz 函数满足以中位数为中心的尾界 `2exp(−t²/(2L²))`，维度 N 不会仅由输入维度自动出现在指数中。参见 [Valettas, 1706.09446v1, abstract](https://arxiv.org/abs/1706.09446v1)。

闭式例子：`f_N(X)=1+tanh(X₁)`，X~N(0,I_N)。该函数正、有界、1-Lipschitz，由对称性均值和中位数均为 1；但 `P(f_N>1/2)=Φ(atanh(1/2))≈0.70860`，与 N 无关。这只说明“正均值+一般 Lipschitz+高斯输入”不足以推出固定阈值下的概率趋一；f_N 不是 SAD 或 L-SPD。

若改写到单位球面，`1+tanh(sqrt(N)U₁)` 的 Lipschitz 常数可达 sqrt(N)，仍须跟踪归一化后的常数。实际几何分数还涉及范数分母、arccos 端点、协方差最小特征值与矩阵对数；不能不加条件假设其全局常数不随维度或近奇异输入变化。这里尚未推导官方分数的紧界。

## 4 理论规则与部署规则分别记录

附录 B.3 / Theorem 4.10 明确给出

```
R = {(s,l): s > τs AND l > τl},   s=SAD, l=LGI
0 < τs < μs,  0 < τl < μl.
```

因此理论几何拒绝使用 AND；接受其补集在纯几何空间等价于至少一个分数不超阈值。联合概率下界使用 union bound，不需要假设两个分数独立。它没有给出可直接部署的阈值数值、校准划分、代码中 top-k 分数与理论 LGI 的数值对应，以及与基础 WM 的最终布尔结合。AUC 不能补全这些字段。详见 [完整评估契约](../docs/EVALUATION_CONTRACT.md#33-判定闭合状态)。
