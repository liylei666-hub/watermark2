# 从代理匹配到普通GS判定的条件审查

本轮闭合了一个解释缺口：连续潜变量距离、加密位一致性、重复投票后的消息准确率、固定阈值接受，是四个不同层次。阶段21的MSE优势只能说明第一个层次的有限步长效果，不能直接推出GS成功。以下是源码审查与基础数学条件，不是新攻击、模型实验或新定理。

同时明确了一项协议差异：CVPR论文采用逐图新的key/nonce；本项目阶段17使用一个固定身份，阶段21使用两个固定身份各两图。原始结果保留为开发诊断，未来独立确认集必须明确逐图加密状态，不能把不同生成种子称为独立水印状态。

取位的实数公式与计算机浮点CDF必须区分：极近0、非有限值等情况不能未经测试就宣称所有正缩放都逐位保持实现输出。本轮证明以实际取位序列相同为精确条件；符号与幅值反例使用远离舍入边界的有限有理数。

## 2. 连续距离为什么不等于消息准确率

令Q为取位，r和z分别是同一目标验证空间中的参考与候选反演。若Q(r)=Q(z)，且验证所用key、nonce、消息及布局相同，则解密和投票输出相同。攻击者无需知道key也能理解这个充分条件，但不能用代理Q(F_s(x))相同替代目标Q(F_t(x))相同。

**MSE与消息准确率没有普遍单调排序。** 考虑一个64次重复、明文全1的抽象列，参考64个坐标全为+1。候选A有33个−0.001，其余+1，MSE为0.516656765625，投票为0；候选B全部+2，MSE为1，投票为1。距离较小者反而恢复错误。这里是公开合成的未加密列；不是模型输出、真实密钥、图像攻击或完整防御反例。

**相同总取位错误也不决定消息错误。** 两个64次重复的全1列，共64次位翻转：全部集中一列时只有一位消息错误；每列32次时两列均平局并输出0，两位消息错误。两例的总取位差及±1表示下的MSE相同，投票结果不同。

在实数l=1取位模型下，对任意α>0：

\[
H(Q(z),Q(r))\leq\min\{d,\ N_r(\alpha)+\|z-r\|_2^2/\alpha^2\},\quad
N_r(\alpha)=\#\{i:|r_i|<\alpha\}.
\]

证明只需把发生符号变化的坐标分成参考幅值小于α、或距离至少α两类。MSE乘维度d才是这里的平方范数。这个界需要参考的逐坐标幅值分布；只有一个MSE均值无法给出有用的判定保证。它是基础计数界，不是本项目的新理论贡献，也未假设真实潜变量误差独立或高斯。

## 3. 重复投票的准确条件

同一流密码状态下，两个密文按位异或同一密钥流，Hamming差保持不变。因此可以讨论每一重复组的位差k_j。令参考解密后该列1的数量为v_j，重复次数m=64，参考投票翻转所需的最少位差为：

\[
q_j=\begin{cases}v_j-32,&v_j\geq33,\\33-v_j,&v_j\leq32.\end{cases}
\]

若k_j<q_j，候选与参考的投票必然相同。于是对于相同登记消息：

\[
\mathrm{BA}(z)\geq\mathrm{BA}(r)-\frac1{256}\sum_j\mathbf1[k_j\geq q_j].
\]

当右端严格大于181/256时，这是普通GS接受的一个充分条件；否则只能说该界不足以保证接受。参考BA=1不意味着q_j很大：33个1或32个1的列距离翻转都只差一位。该界不需各列独立，但q_j属于解密后、目标端的参考状态，不能提供给本项目受限攻击器作为权重、筛选或调参依据。

这些条件仍缺少从代理到目标的关系。代理符号边距不能直接替代目标边距；仅知道目标模型名称、或代理前向等价检查通过，都不能填上这一条件。阶段21的一阶核验失败则进一步限制梯度解释。上述基础界没有测量或解释那20个候选具体为何失败；本轮未重新读取其模型张量做追加探测。

## 4. 方法差异与信息边界

| 待考虑的操作 | 本轮判断 |
|---|---|
| 改为完整代理反演MSE | 已是Imprint核心；同像素对照有机制意义，不是新方法 |
| 保持符号、重采样幅值 | 原论文§3.3已有bin resampling；不能作为新贡献 |
| 只把点匹配换成符号/间隔损失 | 是可讨论的代理目标族，但损失形式本身不足以确立新颖性；未知目标上的符号保留仍未解决 |
| 使用目标解密后投票边距q_j加权 | 超出当前攻击信息权限，只能用于评估端的理论解释 |
| 依据目标BA选择候选或步长 | 超出当前零目标反馈设置 |
| 代理上允许幅值变化的等价集合匹配 | 需要明确区别于已有bin resampling和通用约束优化；尚未选定实现、证明迁移或确立贡献 |

论文依据：[Black-Box Forgery Attacks，arXiv v2 §3.1、§3.3、Appendix A](https://arxiv.org/html/2412.03283v2#S3.SS3)。本轮定向检索包含GS forgery sign loss、margin、hinge、binary cross entropy与orthant；结果不足以证明某个损失族此前不存在。几何论文[v1 C.3](https://arxiv.org/html/2606.29807v1#A3.SS3)讨论过Reforge，因此也不能把“考虑自适应攻击”本身作为区别。

研究准入要求是三项同时成立：新增计算超出已有目标/箱内采样；给出可证伪的跨模型机制；在固定成本和实际交付失真下报告内容、普通GS与完整验证的不同端点。当前没有候选方法满足这三项，不启动新的GPU组。

## 5. 后续独立确认的采样契约

[原论文v2 Appendix A，Deployment Ambiguity](https://arxiv.org/html/2412.03283v2)指出逐图新的nonce和/或密钥，并说明论文实验逐图更新key与nonce。官方类按offset读取固定表，单次调用使用offset至offset+batch_size；改变生成随机种子不会自动更换这些值。[gs_provider.py:83–106、145–153](https://github.com/and-mill/semantic-forgery/blob/ca68950cd7b53b8438a49580f134b2a0db28d778/utils/wm/gs_provider.py#L145-L153)。

阶段17的offset0跨三图复用，阶段21的offset1/2各复用两图，这是已记录的开发配置。它们不等价于论文逐图更新配置；不能将四对方向一致外推为逐图独立密钥情形。攻击器仍只看到每任务一张参考图，本轮没有证据说它利用了多图复用，也不能把现有结果归因为复用漏洞。

未来独立确认需预先冻结：用户消息身份、每张参考的加密key/nonce组合、生成RNG、提示词与任务分组。每张参考使用独立加密组合；同参考的各方法共享同一评估身份做配对。用户身份可按研究问题重复，不能把换用户、换key、换nonce、换生成种子混为一个“新身份”变量。未见的目标材料只由评估端持有；公开仓库中的固定表offset不构成保密权限隔离。正式报告须说明身份/提示词聚类和统计分母。
