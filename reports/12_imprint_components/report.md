# 交付路径组件残差诊断

2026-10-18（Asia/Shanghai）。**在两个已保存固定点和既有扰动上，较大的方向导数偏差主要定位在VAE解码、截断、再编码这一组合映射；拆分计算的链式梯度与原端到端梯度逐位一致。** 这是有限步长下的残差定位，不足以证明截断是原因，也不能推出攻击有效性或优化收益。

## 问题、固定输入与计算

[阶段11](../11_imprint_gradient/report.md)的两个点梯度余弦均为正，原生负梯度仍改善交付目标；但交付自身方向的有限差分偏差约10.0%和6.5%。本次保持同一参考/cover、阶段10更新0/10潜变量、阶段11保存的内部/交付方向、全部正负扰动及半径0.001。所有输入哈希在[协议](../../protocols/12_imprint_components.json)中冻结。

令T(z)为代理VAE解码、[0,1]截断、确定性均值再编码的组合映射，f(y)=MSE(I(y),u)为代理反演后的参考匹配损失。E/D含真实缩放，u来自参考图代理反演。记录：

- **A** = 阶段11端到端梯度与固定方向d的内积。
- **B** = 基点后续反演梯度 `grad_y f(T(z))` 与 `ΔT=[T(z+eps*d)-T(z-eps*d)]/(2eps)` 的内积。
- **C** = 已保存阶段11反演噪声的损失中心差分，以CPU float64复算。
- `A−C=(A−B)+(B−C)`。`A−B`衡量T在该方向、有限半径上的投影线性化残差；`B−C`衡量后续f相应的线性化残差。

实际模型计算只补充基点反演梯度、拆开的T反向传播，以及8个既有扰动的T前向。C直接复用阶段11已保存的噪声张量，未重新执行这些扰动的完整反演。没有优化更新、新候选图、目标模型或目标检测调用。

## 对研究路线的影响

当前证据支持一个受限判断：代理内部优化的部分改善在图像交付后损失，而且局部交付方向的有限步长敏感性主要落在组合VAE映射中。与此同时，阶段10原生优化约91.52%的改善仍保留，阶段11两个梯度正相关，原生方向仍有效。因此不能把原生优化描述为普遍失效，也没有证据把该差距称为主要攻击瓶颈。

**方法决策：当前不把“增加交付路径损失”定为论文方法，不继续叠加相同开发对上的诊断以寻求肯定结论。** 下一项工作是设计可执行的官方Imprint与已有单图VAE匹配比较：明确cover任务、内容和失真代价、计算预算、可完整执行的水印端点与目标信息边界；检查能否识别超出已有方法的独立贡献，再决定独立样本实验。完整几何/语义防御仍需其缺失的官方实现与判定材料，不能由这些代理诊断替代。

当前所有点来自同一开发轨迹；目标迁移收益、完整防御接受、内容达成及新颖性均未被本次诊断验证。阶段11原始容差失败标记和所有原文件保留。
