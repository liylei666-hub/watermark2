本快照把服务器 `/data0/liyanlei/watermark_research` 的阶段 01–05 材料和本会话提示词整理为公开研究档案。服务器原结果、脚本和本机源材料未被改写。

## 收录范围

- 服务器 reports/、runs/、scripts/ 与执行约束共 422 个来源文件。逐文件原始大小/SHA256 见 source_manifest.json；原执行 AGENTS.md 映射至 execution_AGENTS.md，根目录 AGENTS.md 是仓库阅读与执行规则。
- 本机额外 44 个准备、中转及审计材料，来源及 SHA256 见 local_sources.json。
- 五阶段完整原始提示词、阶段 05 GPU 3 修订、其他用户修订；prompts/index.json 记录原始附件/消息来源和哈希。
- 会话导出有 25 条用户消息和 13 条最终交付消息，截止覆盖仓库授权；不包含内部推理、系统/开发者消息、应用上下文和工具原始输出。完整研究细节通过原始产物保留。消息导出范围见 conversation_export.json。
- 新增 GPT 阅读入口、阶段谱系、原始文件导航、合并阅读文档与标准库只读核验工具。

## 公开副本处理

无关服务器用户的姓名及其私有进程/项目路径用占位符替换。每个实际变化文件的原始 SHA256、公开 SHA256 和原因见 publication_transformations.json；GPU 占用/PID及科研数值保留。除清单所述处理外，来源文件按原始字节复制。原始哈希继续表示服务器当时文件，不能把经过隐私处理的公开副本冒充原字节。

模型权重、环境、缓存、临时下载未纳入；这些可达几十 GiB，版本及校验清单已保存。两份重复上游 Git bundle 与论文全文 HTML 通过来源 URL、固定版本、SHA256 记录；上游用 submodule pin 表达。一个 Python 字节码文件不属于源代码或实验结果。具体已枚举排除项见 source_manifest.json；说明见 THIRD_PARTY.md。

没有保存密码、认证令牌或私钥内容。公开文件的高置信凭据模式检查见 secret_scan.json；这是限定模式扫描，不是无泄漏的数学证明。历史文件中的服务器地址、项目路径、GPU UUID 和本机认证文件路径是环境元数据，均不是凭据内容。

## 核验

published_manifest.json 给出本快照的文件大小与 SHA256（它自身及核验结果文件除外，避免递归哈希）。tools/verify_archive.py 只读核对源/公开文件哈希、六份提示词源、原始 CSV、27 份真实目标张量及图像/配置绑定，复算已保存 cosine 的算术值以检查归档一致性，并核对阶段 05 协议、设备记录和描述统计。它不生成新图、不反演、不加载模型。verification.json 保存本次真实执行结果。

所有来源记录中的运行成功、像素验证、模型调用次数和 GPU 占用均属于历史运行证据；发布核验不重演 GPU 实验。绝对路径通过 path_mapping.json 映射到 checkout，机器环境并非随 Git 克隆。

本仓库当前树由当前研究项目组成；Git 提交历史保留原有仓库版本。后续修改应正常提交并保留研究数据的可追溯性。
